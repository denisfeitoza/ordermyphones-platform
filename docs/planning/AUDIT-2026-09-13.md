## P2 — client bugs, perf, i18n, tooling

- **Catalog toggle key mismatch:** CatalogTab invalidates `['app_setting','catalog_source']`, the hook uses `['app-settings','catalog_source']` (5-min stale). Admin's own tab stays in the old mode after flipping LIVE.
- **Import commit** only invalidates `admin-inventory`; availability, flags, summary, location pickers stay stale. Same after `reprice_all` and `set_tier_price`.
- **Workbench save** is sequential per tier with no error path (partial saves, silent).
- **Broken embed:** `listImportProfiles` selects `suppliers(name)` — column doesn't exist (`anon_label`) → 400, panel silently empty. `adminConfig.ts:274`
- **Address edit form** is uncontrolled with `defaultValue`; switching Edit A → Edit B keeps A's values. Add `key={editing.id}`.
- **Order detail** treats fetch errors as "Order not found".
- **Quick order** lets an admin in tier-preview build a priced cart and reach checkout (server rejects; UI shouldn't allow).
- **Cart drawer** allows checkout while prices are still resolving (subtotal undercounts).
- **Approval/reconciliation** deduct from inactive stock locations; the Locations active toggle isn't admin-gated.
- **Order edit** collapses split-location lines into one row (only matters once `order_location_selection` is ON).
- **i18n:** 25 real-mode keys missing in both PT and ES (`Best selling`, `New arrivals`, `Compare`, `In stock`, `Unlocked/Locked`, `Request access for pricing`, `PDF`, `CSV`, all 12 Team page strings…). Hardcoded `'en-US'` dates in `RealOrders`, `TeamPage`, `OrderDetailPage`, `lib/export.ts`, `lib/format.ts`. `ContactPage`/`HelpPage`/Payment/Wishlist/Tier/InventoryApi are untranslated (mock-era).
- **Perf advisor:** `order_events_read` re-evaluates `auth.uid()` per row (wrap in `(select …)`); unindexed FKs on hot paths (`order_items.variant_id`, `order_items.location_id`, `inventory.location_id`, `stock_movements.location_id`, `reconciliation_queue.*`); 17 tables with duplicate permissive SELECT policies (merge "read" into the "write FOR ALL" policy).
- **Tooling:** `npm run lint` is broken — ESLint 9 installed, no `eslint.config.js`. No CI at all (no `.github/workflows`): typecheck/lint/test never run on push.
- **Stale copy:** `ViewAsPage.tsx:118` still claims addresses are client-side only.
- **Dead compute:** `DashboardPage`, `CustomersPage`, `ReportsPage` call `useAdminData()` (mock) unconditionally in real mode.

Sub-accounts can't invite; tier never client-supplied; owners see only their own invite tokens; sub-accounts can't read owner/sibling profiles or orders; `redeem_invite` rolls back atomically. `catalog_listing`/`my_order_items`/`variant_price_for_me` expose no cost, vendor grade or supplier name.
