What this gives the platform

  • Live tracking. Today your team types a tracking number by hand and the customer has to check FedEx themselves. After this, the order page shows the real status — in transit, out for delivery, delivered, or a problem — with every scan and its location.
  • Shipping quotes. At checkout the customer sees an estimated shipping cost from the warehouse that holds the stock to their ZIP code. It is an estimate for information only: it is not added to the order total, and shipping keeps being invoiced separately by your team.

Using the FedEx API is free. You keep paying only for the shipments you actually send, at your own FedEx rates. Nothing about your pricing or billing changes.

Step 1  ·  Create a fedex.com login (5 minutes)

If you already sign in to fedex.com, skip to Step 2 and use that login.

1Go to fedex.com/register

2Fill in the form. It asks only for:

  • Your name
  • Email address and phone number
  • Your address (country, street, city, state, ZIP)
  • Company name — optional, but please fill it in
  • A user ID and password of your choice

No payment details at this stage. This login is free and does not ask for a credit card, a tax ID, or business documents. It is only the account you use to sign in.

Step 2  ·  Create the API project (10 minutes)

1Go to developer.fedex.com and sign in with the login from Step 1.

2FedEx asks what kind of company you are. Choose “A company that ships with FedEx”.

The other option is for software vendors who resell FedEx integrations, and it triggers a longer approval process we do not need.

3Open My Projects and click Create Project.

4Fill in the project:

Field What to enter
Project Name OrderMyPhones_Platform
APIs Select “Ship, Rate & Other APIs”.
Do not select Advanced Integrated Visibility — it is the one paid product, and selecting it makes FedEx ask for a billing account we do not need.
Countries The countries you ship from and to. United States is enough if you only ship domestically; add any others you already ship to.
Terms Accept the FedEx Developer Portal License Agreement, then click Create.

5On the project page, open the Test Key tab. FedEx shows three values immediately — this is what we need.

You do not need a FedEx shipping account for this. The Test Key tab includes a test account number that FedEx creates for you, so the platform can be built and tested before anything goes live.

Step 3  ·  Send us these three values

Copy them exactly as FedEx shows them, from the Test Key tab:

What FedEx calls it Value

Please do not send the Secret Key by email. Send it over WhatsApp, or send the API Key and account number one way and the Secret Key another. If you prefer, we can walk you through pasting the three values straight into the platform's settings yourself, so nobody else ever sees them. If the key is ever exposed, you can delete it and generate a new one in the same tab.

Also needed: your warehouse addresses

A shipping quote needs a starting point, and the platform currently has warehouse names but no addresses. Please fill in the ZIP code for each location — city and state help, but the ZIP is what we need:

Warehouse (as it appears in the platform) City State ZIP code
Texas (TX1)
Tennessee (TN1)
Warehouse 23 (W23-ATT)

Warehouse 23 holds roughly 94% of the stock, so its ZIP is the most important one. If a location does not ship directly to customers, just tell us and we will leave it out of the quotes.

Later, only when you want to go live

Everything above uses the FedEx test environment, which is enough to build and demo the feature. When you want real tracking and real rates on the live site, FedEx needs a production key, and that requires a regular 9-digit FedEx shipping account. If you already have one, we only need the number. If you don't, opening one at fedex.com/en-us/open-account.html asks for:

  • Company name and business address
  • Proof of business registration and your tax ID (EIN)
  • A contact person
  • A credit card for billing — the account itself is free, but FedEx places a temporary $1 hold to verify the card

Printing FedEx labels from the admin panel is a separate feature. FedEx reviews sample labels before allowing it, which takes days to weeks, so it is not part of this setup. Tracking and quotes need no such review.

Common questions

Does this cost anything?

No. API access is free, and the test environment charges nothing at all. You keep paying only for real shipments, at your existing rates.

Will this change my shipping prices or who I ship with?

No. The platform only reads FedEx information. It does not create shipments, buy labels, or change any rate you have negotiated.

I already have a FedEx account. Can we use it?

Yes, and it makes the last step easier — send us the 9-digit account number and we can prepare the live setup at the same time. Please still create the developer project, because that is where the keys come from.

What if I pick the wrong option in the project?

Nothing breaks. The project can be edited, and keys can be regenerated or deleted at any time.

Who can see these keys?

They are stored in the platform's server-side settings. They are never included in the website's code and are never visible to customers or to your staff in the admin panel.
